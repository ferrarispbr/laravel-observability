# Laravel Observability

Projeto de estudo voltado à implementação de observabilidade em uma API Laravel.

A aplicação será instrumentada para expor métricas ao Prometheus e visualizá-las no Grafana, permitindo acompanhar disponibilidade, desempenho e comportamento da API.

## Tecnologias

- Laravel
- PHP
- Prometheus
- Grafana
- Docker

## Objetivos

- Construir uma API com Laravel.
- Expor métricas técnicas da aplicação.
- Coletar métricas com Prometheus.
- Criar dashboards no Grafana.
- Monitorar saúde, requisições, erros e desempenho da API.
